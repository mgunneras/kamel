# Kamel

Chrome extension that translates Swedish subtitles to English on [TV4 Play](https://www.tv4play.se).

It uses Chrome's built-in on-device translator, so nothing is sent to a server, and it translates each line before it is shown, so there is no delay.

## Install

Needs desktop Chrome 138 or newer.

1. Download or clone this repo.
2. Open `chrome://extensions` and turn on Developer mode.
3. Click "Load unpacked" and pick the folder.
4. Open a programme on TV4 Play and turn on Swedish subtitles in the player.

The first time, Chrome may need to download its Swedish language pack. Click the page once to let it start.

## Use

- Press `T` on the player page to switch between English and the original.
- Click the extension icon for settings: on/off, show Swedish too, text size, background.
